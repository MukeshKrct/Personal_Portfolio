# Mukesh S — Portfolio Website (Pro Edition)

A responsive static portfolio for Mukesh S, a 2026 Computer Science Engineering graduate focused on Python, AI/ML, computer vision, web development, and cloud fundamentals.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Blue theme based on `#92A8D1`, navy text, and light surfaces
- Light/dark theme toggle (preference is saved locally when browser storage is available)
- Animated role label, scroll progress, section-aware navigation, and reveal effects
- Filterable project cards and accessible project case-study dialogs
- Custom project visuals for Vehicle Damage Detection, LoanClear, AI Resume Analyzer, and Personal Portfolio Website
- Blue portfolio design preview images included as local optimized WebP assets
- Direct email, GitHub, LinkedIn, phone, and resume download links
- Reduced-motion support, keyboard-accessible navigation, and basic SEO metadata

## Run locally

1. Extract `Mukesh_Portfolio_Pro_Final.zip`.
2. Open the extracted folder in VS Code.
3. Run `index.html` with the Live Server extension, or open it directly in a browser.
4. Keep `index.html`, `styles.css`, `script.js`, `favicon.svg`, and the `assets` folder together.

The site does not require a build step, package installation, or backend server. Google Fonts are optional; system font fallbacks are configured.

## Publish with GitHub Pages

1. Create a GitHub repository named `mukesh9696fc.github.io` (or use another repository name).
2. Upload the contents of this folder to the repository root; `index.html` must be at the root.
3. For a repository named `mukesh9696fc.github.io`, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
4. Wait for the deployment workflow to finish, then open `https://mukesh9696fc.github.io/`.
